# PipelineMedic — Devpost planning

This project began in an empty workspace on September 24, 2026 for Build With AI: Basics.

The official challengepost/learn-ai-basics skill pack is available locally in `.devpost-pack/skills/`.
The guided planning workflow begins with `1-start`, followed by scope, PRD, specification, build, and submission preparation.

Confirmed direction: a JavaScript/Next.js CI/CD failure diagnosis application with cloud and on-premises deployment options, cloud or self-hosted AI advice, and an MCP interface sharing the diagnosis service.

Deployment preference: containerized. If persistence is needed, use SQLite or PostgreSQL.

Planning documents will record the actual interview and decisions as the workflow progresses. Personal learning context is excluded from Git by default.
